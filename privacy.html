Privacy

Short, because there isn't much to say.

This website

vibebunch.com has no accounts, no forms and no cookies. It is a plain page hosted on GitHub Pages.

Counting visits

We count visits so members can see whether the site is useful. When a page opens, a short script sends one thing: which page it was, such as /privacy.html.

To count each visitor once a day without cookies, the counter scrambles your IP address and browser name together with a random value that changes daily. It keeps that scrambled code for the rest of the day. When the next day's first visit arrives, the code and that day's random value are deleted, so the code can't be traced back to you or matched to another day. The counter doesn't store your IP address.

What stays is totals: page views and visitors per day, and views per page. Nothing about where you are, what device you use or which link brought you here, and nothing is saved on your device.

If your browser sends Do Not Track or Global Privacy Control, or blocks scripts, you aren't counted at all.

The counter and the totals live on the members page, which runs on Cloudflare. Like any web host, Cloudflare sees your IP address when the script reaches it. Only members can see the totals.

The members page

When you sign in to the members page, with Google, GitHub or an emailed code, we receive your name and email address. We use them for one thing: checking that you're on the members list so we can let you in.

We don't sell them, share them or send you anything because of them. Sign-in is handled by Cloudflare, which keeps a log of sign-ins as part of running the service.

Questions or removal

Ask in the group chat or tell the host at the next brunch, and we'll take you off the members list.
