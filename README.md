# website

The source of [vibebunch.com](https://vibebunch.com).

**This repository is public.** Anyone can read every file in it, and its entire history.
Nothing private belongs here. See
[CONTRIBUTING](https://github.com/vibebunch/.github/blob/main/CONTRIBUTING.md) before your
first change.

## How it works

Plain HTML and CSS. There is no build step and nothing to install. Edit a file, open a
pull request, and the site updates itself a minute or two after it is merged.

| File | What it is |
|---|---|
| `index.html` | The front page. Meetings and the project gallery are in here. |
| `whats-public.html` | A live view of which of our repositories the public can see. |
| `style.css` | All the styling. |
| `CNAME` | Holds our domain name. Do not delete this. |

## Making a change

The easiest route is entirely in the browser. Open the file, click the pencil icon, edit,
then choose "Create a new branch for this commit" and open a pull request. Any member can
review and merge it.

Two spots are marked with comments in `index.html` showing exactly where to add a meeting
or a project. You do not need to understand the rest of the file to use them.

## Adding your project to the gallery

Your project stays in your own GitHub account. The gallery just links to it. Copy one of
the existing blocks in the "What we have built" section, change the link, the name and the
one line description, and open a pull request.
